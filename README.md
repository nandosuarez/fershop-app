# FerShop v2

Version operativa vigente de FerShop para administrar pedidos de WhatsApp, pagos, clientes, productos, inventario, ordenes de compra, gastos y usuarios.

## Aplicacion vigente

El codigo de produccion se encuentra en [`fershop-v2/`](./fershop-v2/README.md).

- Next.js 16 y React 19.
- PostgreSQL administrado en Render.
- Acceso privado con usuarios, claves y roles.
- Respaldo operativo descargable.
- Despliegue definido en [`render.yaml`](./render.yaml).

La version Python anterior se conserva en la etiqueta Git `v1.0.0-legacy` y ya no se despliega desde `main`.
